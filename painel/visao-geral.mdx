**Onde fica**: é a tela inicial depois de entrar na conta.

## Descrição

O painel é onde você cria instâncias, conecta números, acompanha mensagens e
ajusta o comportamento de cada instância. Esta página descreve a organização do
painel e indica a página de cada área.

## Entrada no painel

Ao abrir o endereço do painel, o painel redireciona você. Não há uma tela inicial
própria.

- Sem sessão ativa: você vai para a tela de entrada. Veja [Conta e assinatura](/painel/conta-e-assinatura).
- Com sessão ativa: você vai para a lista de instâncias.

O endereço `dash` também redireciona para a lista de instâncias. A lista de
instâncias é a porta de entrada do painel.

## Menu lateral

O menu lateral é fixo em todas as telas. Ele tem dois grupos.

### Navegação

| Área | Função | Página |
|---|---|---|
| **Instâncias** | Lista as instâncias da conta e dá acesso a cada uma | [Instâncias](/painel/instancias) |
| **Configurações** | Dados da conta e do cadastro | [Conta e assinatura](/painel/conta-e-assinatura) |
| **Global API Key** | Chave da Instance API, para criar e administrar instâncias | [Chave de API global](/painel/chave-de-api-global) |
| **Minha assinatura** | Abre o portal do cliente em uma aba nova | [Conta e assinatura](/painel/conta-e-assinatura) |

**Minha assinatura** não é uma tela do painel. O item abre o portal do cliente em
uma aba nova. No portal, você vê as faturas, altera a forma de pagamento e
cancela a assinatura.

### Suporte

Três atalhos abrem em aba nova: **Documentação** (este site), **Fale com o Zack**
(atendimento por WhatsApp) e **Comunidade**. Abaixo deles, **Sair** encerra a
sessão.

## Idioma do painel

O painel está disponível em português, inglês, espanhol, alemão, italiano e
turco. O menu de idioma mostra a bandeira do idioma atual. Ele fica no rodapé do
menu lateral, no topo de cada tela e nas telas de login e de cadastro.

No primeiro acesso, o painel usa o idioma do navegador se ele for um desses
seis. Para os outros idiomas, o painel usa português. Para trocar o idioma,
selecione-o no menu de idioma. O painel guarda a escolha por um ano neste
navegador.

## Duas chaves diferentes

O painel expõe duas chaves. Elas não são intercambiáveis:

| Chave | Onde fica | Função |
|---|---|---|
| **Global API Key** | Menu lateral > Global API Key | Criar e administrar instâncias pela Instance API |
| **Chave de API da instância** | Na linha da instância, na lista | Enviar mensagens e operar a instância pela API |

A diferença entre as duas, com o cabeçalho HTTP de cada uma, está em
[Chave de API global](/painel/chave-de-api-global).
