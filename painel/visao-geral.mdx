**Onde fica**: é a tela inicial após entrar na conta
**Rota**: `dash`

O painel é onde você cria instâncias, conecta números, acompanha mensagens e ajusta o
comportamento de cada conexão. Esta página descreve como ele é organizado e leva para a
página de cada área.

## Como você chega ao painel

Ao abrir o endereço do painel, você é redirecionado automaticamente — não existe uma tela
inicial própria:

- **Sem sessão ativa**: você vai para a tela de entrada, descrita em
  [Conta e assinatura](/painel/conta-e-assinatura).
- **Com sessão ativa**: você vai direto para a lista de instâncias.

O mesmo vale para o endereço `dash`: ele sempre redireciona para a lista de instâncias. Na
prática, **a lista de instâncias é a porta de entrada do painel**.

## O menu lateral

O menu lateral é fixo e acompanha você em todas as telas. Ele tem dois grupos.

### Navegação

| Área | O que faz | Página |
|---|---|---|
| **Instâncias** | Lista todas as instâncias da conta e dá acesso a cada uma | [Instâncias](/painel/instancias) |
| **Configurações** | Dados da sua conta e do seu cadastro | [Conta e assinatura](/painel/conta-e-assinatura) |
| **Global API Key** | Chave usada na Instance API, para criar e administrar instâncias | [Chave de API global](/painel/chave-de-api-global) |
| **Minha assinatura** | Abre o portal do cliente em uma nova aba | [Conta e assinatura](/painel/conta-e-assinatura) |

**Minha assinatura** não é uma tela do painel: o item gera um link para o portal do cliente e
o abre em uma aba nova. É lá que você vê faturas, altera a forma de pagamento e cancela.

### Suporte

Três atalhos que também abrem em aba nova: **Documentação** (este site), **Fale com o Zack**
(atendimento por WhatsApp) e **Comunidade**. Abaixo deles fica **Sair**, que encerra a sessão.

## Duas chaves diferentes

O painel expõe duas chaves, e elas não são intercambiáveis:

| Chave | Onde fica | Para que serve |
|---|---|---|
| **Global API Key** | Menu lateral → Global API Key | Criar e administrar instâncias pela Instance API |
| **Chave de API da instância** | Na linha da instância, na lista | Enviar mensagens e operar aquela instância pela API do Manager |

A diferença entre as duas, com o cabeçalho HTTP de cada uma, está em
[Chave de API global](/painel/chave-de-api-global).
