**Onde fica**: menu lateral > **Tags**.

## Descrição

Tags são rótulos coloridos aplicados às instâncias. Use tags para identificar as
instâncias pelo caso de uso: clientes VIP, ambiente de teste, um cliente por tag.
As tags aparecem na [lista de instâncias](/painel/instancias) e servem de filtro.

Cada tag pertence ao usuário que a criou. Outros usuários não veem as suas tags.

## Limites

| Limite | Valor |
|---|---|
| Tags no catálogo | 50 |
| Tags por instância | 5 |
| Caracteres no nome | 30 |

Ao atingir um limite, o painel informa o motivo e desabilita o botão
correspondente.

## Criar uma tag

Há dois caminhos. Os dois produzem a mesma tag.

- **Na instância**: na lista de instâncias, abra o seletor de tags da linha.
  Digite o nome, escolha a cor e confirme. A tag já nasce aplicada à instância.
- **Na tela de Tags**: clique em **Nova tag**. Preencha o nome e a cor.

O nome é único por usuário. A comparação ignora maiúsculas e minúsculas: se
existe `Cliente VIP`, digitar `cliente vip` mostra a tag existente. A acentuação
é considerada: `Órgão` e `Orgao` são tags diferentes.

### Cores

A cor vem de uma paleta fixa de dez cores. A paleta garante a legibilidade nos
temas claro e escuro. Não há campo de cor livre.

O nome da tag fica sempre visível junto da cor.

## Aplicar e remover

No seletor de tags de uma instância, clique em uma tag para aplicar. Clique de
novo para remover. Remover a tag da instância não a exclui do catálogo.

Quando a instância já tem 5 tags, as outras ficam desabilitadas até você remover
uma.

## Tela de Tags

A tabela lista as tags com a cor, o nome e o número de instâncias em que cada uma
está aplicada.

- **Editar** altera o nome e a cor. A alteração aparece em todas as instâncias
  que usam a tag. As instâncias apontam para a tag, não guardam uma cópia do nome.
- **Excluir** remove a tag do catálogo e de todas as instâncias.

## Excluir uma tag

<Warning>
**A exclusão não pode ser desfeita.** Excluir uma tag a remove de todas as
instâncias em que está aplicada. Antes de confirmar, o painel informa quantas
instâncias serão afetadas.
</Warning>

As instâncias não são alteradas. Elas só deixam de ter a tag. As outras tags
delas permanecem.

Excluir uma instância tem o efeito inverso: as tags dela deixam de estar
aplicadas, mas continuam no catálogo.

## Filtrar instâncias por tag

Na lista de instâncias, o filtro **Tags** aceita uma ou mais tags. A lista mostra
as instâncias com qualquer uma das tags selecionadas.

- **Sem tag** mostra só as instâncias sem tag.
- O filtro se combina com a busca por nome e com o filtro de status.
- O filtro fica no endereço da página. Recarregar mantém a visualização, e o link pode ser compartilhado.

## Pela API

Tudo o que a tela faz está na **Instance API**, na aba **Instance API Reference**:
listar, criar, alterar e excluir tags, aplicar e remover tags em instâncias, e
filtrar a listagem com os parâmetros `tag_ids` e `untagged`.

O campo `tags` acompanha cada instância no retorno de `GET /instances` e
`GET /instances/{instanceId}`. É um campo novo. Nenhum campo anterior mudou.

<Warning>
`DELETE /tags/{tagId}` exclui imediatamente, sem confirmação. A contagem de
instâncias afetadas está em `GET /tags`, no campo `instanceCount`. Consulte o
valor antes de excluir.
</Warning>
