**Onde fica**: **Instâncias** > selecione a instância > **Grupos**.

## Descrição

A tela mostra os grupos e as comunidades de que o número conectado participa.
Ela serve para consulta: copiar o ID de um grupo para a API ou para o n8n, ver os
participantes e as configurações, e copiar o link de convite. Para alterar um
grupo, use a API. Veja [Grupos](/functions/groups).

A aba **Grupos** aparece só em instâncias conectadas por QR Code.

A lista tem as colunas **Nome**, **Participantes** e **ID**. A coluna **ID** não
aparece em telas estreitas.

## Encontrar um grupo

- Digite parte do nome ou do ID no campo **Buscar por nome ou ID**.
- Quando o número participa de uma comunidade, use os filtros **Todos**,
  **Grupos** e **Comunidades**. Cada filtro mostra a quantidade de itens.

Na lista, o selo **Comunidade** marca uma comunidade. O selo **Avisos da
comunidade** marca o grupo de avisos de uma comunidade.

## Copiar o ID de um grupo

Clique no ID, na coluna **ID** ou nos detalhes do grupo. O painel mostra **ID
copiado**.

## Ver os detalhes

Clique no nome do grupo. O painel abre os detalhes ao lado da lista:

| Seção | Conteúdo |
|---|---|
| **ID do grupo** | O ID e o botão **Copiar link de convite**. |
| **Configurações** | **Quem envia mensagens**, **Quem edita os dados**, **Entrada pelo link** e **Mensagens temporárias**. |
| **Faz parte da comunidade** | A comunidade do grupo. Clique no nome para abrir a comunidade. |
| **Participantes** | O número ou o LID de cada participante, com os selos **Criador** e **Admin**. Com mais de 12 participantes, aparece o campo **Buscar participante**. |

Nos detalhes de uma comunidade, a seção **Grupos da comunidade** lista os grupos
dela. As seções **Configurações** e **Participantes** não aparecem.

<Note>
Quando o número conectado não é administrador do grupo, o WhatsApp pode ocultar
o telefone de alguns participantes. Nesses casos, a lista mostra o LID.
</Note>

## Copiar o link de convite

Clique em **Copiar link de convite**. O painel mostra **Link de convite
copiado**.

Só administradores do grupo podem ver o link. Se o número conectado não é
administrador, o painel mostra **Só administradores do grupo podem ver o link de
convite.**
