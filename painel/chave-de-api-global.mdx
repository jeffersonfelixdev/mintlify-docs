---

**Onde fica**: menu lateral > **Global API Key**.

## Descrição

A tela **Configurar sua Global API Key** (`dash/api-key`) administra a chave da
conta. Ela é diferente da chave de cada instância. A confusão entre as duas é a
causa mais comum de erro `401`.

## Qual chave usar

| | **Chave global** | **Chave de instância** |
|---|---|---|
| **Nome no painel** | Global API Key | Chave da API (X-Api-Key) |
| **Onde fica** | Menu lateral > Global API Key | Na linha da instância, em [Instâncias](/painel/instancias) |
| **Escopo** | A conta inteira | Uma única instância |
| **API** | Instance API | API da instância |
| **Cabeçalho** | `Authorization: Bearer <chave>` | `x-api-key: <chave>` |
| **Função** | Criar, renomear, listar e excluir instâncias | Enviar mensagens e operar a instância |
| **Referência** | Aba **Instance API Reference**. Exemplo: [Obtém todas as instâncias](/api-reference/instâncias/obtém-todas-as-instâncias) | Aba **API Reference**. Exemplo: [Obter configurações](/api-reference/configurações/obter-configurações) |

Regra: se a chamada cria ou administra instâncias, use a chave global. Se a
chamada opera dentro de uma instância (enviar mensagem, ler chat, configurar
webhook), use a chave da instância.

O conceito das duas chaves está em [Autenticação](/definitions/authentication).

## Criar a chave

Sem nenhuma chave, a tela mostra **Não há uma chave global criada** e o botão
**Criar chave global**.

<Steps>
  <Step title="Crie">
    Clique em **Criar chave global**. O painel abre o diálogo **Nova Chave Global Criada**.
  </Step>
  <Step title="Copie a chave">
    Clique no botão de cópia. O painel confirma com **Chave copiada para a área de transferência!**
  </Step>
  <Step title="Guarde a chave">
    Salve a chave onde a sua aplicação vai lê-la. Depois, clique em **Entendi, fechar**.
  </Step>
</Steps>

Se a criação falhar, o painel mostra **Ocorreu um erro ao criar chave global**.

<Warning>
**A chave aparece uma única vez.** Depois de fechar o diálogo, nem você nem o
suporte conseguem ver a chave de novo. Copie a chave antes de fechar o diálogo.
Se você perder a chave, use **Rotacionar** para gerar outra.

Não coloque a chave em código versionado, em mensagem de suporte nem em qualquer
lugar público.
</Warning>

## Rotacionar

O botão **Rotacionar** substitui a chave atual por uma nova. Use a rotação quando
você perdeu a chave ou suspeita de vazamento.

<Warning>
**A rotação invalida a chave anterior na hora.** Toda aplicação que ainda usa a
chave antiga recebe erro de autenticação imediatamente. Não há período de
convivência entre as duas chaves.

Para rotacionar sem interromper o serviço: tenha o acesso às aplicações pronto
antes de confirmar. Rotacione, copie a chave nova e atualize as aplicações em
seguida. A indisponibilidade dura o tempo entre a rotação e a atualização.
</Warning>

<Steps>
  <Step title="Inicie a rotação">
    Clique em **Rotacionar**. O painel abre **Confirmar rotação de chave**.
  </Step>
  <Step title="Confirme">
    Clique em **Sim, rotacionar chave**.
  </Step>
  <Step title="Copie a chave nova">
    A chave nova aparece no diálogo **Nova Chave Global Criada**. Copie e guarde a chave. Ela também aparece uma única vez.
  </Step>
  <Step title="Atualize as aplicações">
    Substitua a chave em todas as aplicações que usam a Instance API.
  </Step>
</Steps>

## Excluir

O botão **Excluir chave global** abre o diálogo **Confirmar exclusão**.

<Warning>
**A exclusão não pode ser desfeita.** A conta fica sem chave global. Toda chamada
à Instance API falha até você criar outra chave. As instâncias existentes não são
excluídas e continuam a operar com as próprias chaves. Só a administração pela
Instance API para.

Para trocar a chave, use **Rotacionar**, que cria a substituta no mesmo passo.
</Warning>

Clique em **Sim, excluir**. Sucesso: **Chave global excluída com sucesso**.
Falha: **Ocorreu um erro ao excluir chave global**.
