**Onde fica**: menu lateral > **Instâncias**.

## Descrição

A lista de instâncias é a porta de entrada do painel. Você chega nela ao entrar
na conta. Cada instância corresponde a um número. O conceito está em
[Conexão com o WhatsApp](/definitions/connection).

Sem nenhuma instância, a tela mostra **Nenhuma instância encontrada** e o atalho
**Crie uma instância agora**.

## Colunas da lista

| Coluna | Conteúdo |
|---|---|
| **Nome** | O rótulo da instância |
| **ID** | O identificador usado nas chamadas de API |
| **Chave da API (X-Api-Key)** | A chave da instância, oculta por padrão |
| **URL** | O endereço da instância |
| **Versão** | A versão em execução |
| **Tipo** | A forma de conexão |
| **Telefone** | O número conectado |
| **Status** | **Conectado**, **Desconectado** ou **Não conectado** |
| **Ações** | O menu de ações da linha |

A chave fica mascarada. Use **Mostrar chave** e **Ocultar chave** para
alternar. Esta é a chave da instância, enviada no cabeçalho `x-api-key`. A chave
da conta está em [Chave de API global](/painel/chave-de-api-global).

## Buscar e filtrar

- **Pesquisar por nome...** filtra a lista pelo rótulo.
- **Status da conexão** filtra por estado. **Todos os status** desliga o filtro.
- **Tags** filtra por uma ou mais tags. **Sem tag** mostra as instâncias sem tag.
- Os filtros se combinam.
- A lista é paginada, com o indicador **Página X de Y**.

O filtro de tags fica no endereço da página. Recarregar mantém a visualização, e
o link pode ser compartilhado.

## Tags

Cada linha mostra as tags da instância. Quando não cabem todas, o indicador
**+N** mostra as restantes.

O botão de tag ao lado do nome abre o seletor. Clique em uma tag para aplicar.
Clique de novo para remover. Para criar uma tag, digite o nome e escolha a cor.

Limites e exclusão estão em [Tags](/painel/tags).

## Criar uma instância

<Steps>
  <Step title="Inicie">
    Clique em **Nova instância**. O painel abre **Criar nova instância**, com o aviso de custo mensal.
  </Step>
  <Step title="Confirme">
    Clique em **Sim, criar nova instância**.
  </Step>
</Steps>

O painel confirma com **Instância criada com sucesso**.

Com a assinatura em atraso, o botão fica desabilitado, com a mensagem **É preciso
regularizar a assinatura para criar uma instância.** Veja
[Conta e assinatura](/painel/conta-e-assinatura).

## Ações de cada instância

| Ação | Função | Efeito na conexão ativa |
|---|---|---|
| **Copiar ID** | Copia o identificador. Confirma com **ID copiado** | Nenhum |
| **Copiar URL** | Copia o endereço. Confirma com **URL copiada** | Nenhum |
| **Copiar X-Api-Key** | Copia a chave da instância. Confirma com **X-Api-Key copiada** | Nenhum |
| **Editar nome da instância** | Abre um diálogo para trocar o rótulo | Nenhum |
| **Conectar instância** | Abre o fluxo de conexão | Inicia uma conexão nova |
| **Desconectar instância** | Encerra a sessão do número | Encerra a conexão. O status vai para **Desconectado**. A instância para de enviar e receber até reconectar |
| **Reiniciar instância** | Reinicia o serviço da instância | Interrompe o atendimento durante o reinício. A conexão volta ao fim |
| **Excluir instância** | Remove a instância da conta | Irreversível. Veja abaixo |

Durante a execução, a tela mostra **Desconectando instância...**, **Reiniciando
instância...** ou **Excluindo instância...**. Ao terminar: **Instância
desconectada**, **Instância reiniciada** ou **Instância excluída**. Se o reinício
falhar: **Ocorreu um erro ao reiniciar a instância. Tente novamente mais tarde.**

### Renomear

O diálogo **Editar nome da instância** tem o campo **Nome da instância**, de
texto livre e obrigatório.

Sucesso: **Nome da instância atualizado com sucesso**. Falha: **Erro ao atualizar
nome. Tente novamente mais tarde.** Renomear não afeta o ID, a chave nem a
conexão.

### Excluir

<Warning>
**A exclusão não pode ser desfeita.** Ao excluir uma instância:

- A instância sai da lista. O ID e a chave de API deixam de funcionar. Toda integração que os usa falha.
- A conexão com o número é encerrada.
- O log de mensagens da instância deixa de ser acessível pelo painel. Exporte ou consulte o histórico antes de excluir.
- Para usar o mesmo número de novo, crie uma instância nova e conecte-a. Ela terá outro ID e outra chave.

Para parar temporariamente, use **Desconectar instância**, que é reversível.
</Warning>

O diálogo **Confirmar exclusão** pede a confirmação. Clique em **Sim, excluir**.

Instâncias criadas por um parceiro não são excluídas pelo painel. A mensagem
**Instância criada pelo parceiro. Faça a exclusão na aplicação do parceiro**
indica que a exclusão deve ser feita no sistema de quem a criou.

## Painel da instância

Ao abrir uma instância, você chega ao painel dela, na rota
`dash/instances/[id]`.

### Indicadores

Quatro cartões no topo. Cada um tem o atalho **Ver mensagens**, que abre o log já
filtrado:

| Indicador | Contagem |
|---|---|
| **Em Processamento** | Mensagens em processamento neste momento |
| **Na fila** | Mensagens que aguardam processamento |
| **Com falha** | Mensagens que terminaram em erro |
| **Mensagens processadas** | Total processado |

O conceito de fila está em [Fila de mensagens](/definitions/queue).

### Resumo

O cartão **Resumo** mostra o volume da instância:

- Mensagens processadas hoje.
- Mensagens processadas este mês.
- Mensagens processadas no mês passado.
- Mensagens processadas nos últimos 90 dias.
- Média de mensagens processadas por dia.

Para investigar uma mensagem, use o [Log de mensagens](/painel/log-de-mensagens).
