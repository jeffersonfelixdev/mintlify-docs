---
title: Number format
description: "The valid phone number format in requests"
---

## Rule

Enter the complete phone number, with the country code. The `+` sign is
optional.

Do not format the number. Do not use parentheses, spaces, or dashes.

Example of a number from Brazil: `5511912345678`.

## Automation tools

If you use n8n, Make, or a similar tool, check whether it has a feature to format
phone numbers. Remove the formatting before you send the number to ZapperHub.
