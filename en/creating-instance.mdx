## Description

An instance is a WhatsApp number connected to ZapperHub. Each number needs one
instance. One account can have many instances.

Each instance is an isolated service in the ZapperHub infrastructure. One
instance does not affect the operation of another instance. An instance with an
unofficial connection works as a WhatsApp Web session.

## Preliminary requirements

- An active ZapperHub account.
- A subscription in good standing. With an overdue subscription, the panel does not create instances.

## Procedure

<Steps>
  <Step title="Open the panel">
    Go to [app.zapperhub.com/dash](https://app.zapperhub.com/dash).
  </Step>
  <Step title="Start the creation">
    Click **New instance**.
  </Step>
  <Step title="Confirm">
    Read the cost notice and click **Yes, create new instance**.
  </Step>
  <Step title="Wait">
    ZapperHub creates the instance in a few seconds. The new instance appears in the list.
  </Step>
</Steps>

## Result

The instance appears in the list with the status **Not connected**. The next
step is to [connect WhatsApp](/en/connecting-whatsapp).

<Note>
**Billing.** Each instance has a fixed monthly price. At creation, ZapperHub
charges the amount for the days until the invoice closes. At deletion, ZapperHub
credits the unused days on the next invoice.
</Note>
