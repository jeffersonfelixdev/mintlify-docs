## Description

A chat is the set of messages exchanged with one contact, group, or community.

## Operations

The API supports these operations on a chat:

- Archive and unarchive.
- Mute and unmute notifications.
- Pin and unpin.
- Delete.

The routes are in the *Chat* section of the [API Reference](/api-reference).
