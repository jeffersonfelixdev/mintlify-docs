**Where it is**: **Instances** > select the instance > **Groups**.

## Description

The screen shows the groups and the communities that the connected number
participates in. It is for viewing: copy the ID of a group for the API or for
n8n, see the participants and the settings, and copy the invite link. To change
a group, use the API. Refer to [Groups](/en/functions/groups).

The **Groups** tab is shown only on instances connected by QR Code.

The list has the columns **Name**, **Participants**, and **ID**. The **ID**
column is not shown on narrow screens.

## Find a group

- Type part of the name or of the ID in the **Search by name or ID** field.
- When the number participates in a community, use the **All**, **Groups**, and
  **Communities** filters. Each filter shows the number of items.

In the list, the **Community** badge identifies a community. The **Community
announcements** badge identifies the announcement group of a community.

## Copy the ID of a group

Click the ID, in the **ID** column or in the group details. The panel shows **ID
copied**.

## See the details

Click the name of the group. The panel opens the details next to the list:

| Section | Content |
|---|---|
| **Group ID** | The ID and the **Copy invite link** button. |
| **Settings** | **Who sends messages**, **Who edits group info**, **Joining with the link**, and **Disappearing messages**. |
| **Part of the community** | The community of the group. Click the name to open the community. |
| **Participants** | The number or the LID of each participant, with the **Creator** and **Admin** badges. With more than 12 participants, the **Search participant** field is shown. |

In the details of a community, the **Community groups** section lists its
groups. The **Settings** and **Participants** sections are not shown.

<Note>
When the connected number is not an admin of the group, WhatsApp can hide the
phone of some participants. In that case, the list shows the LID.
</Note>

## Copy the invite link

Click **Copy invite link**. The panel shows **Invite link copied**.

Only group admins can see the link. If the connected number is not an admin,
the panel shows **Only group admins can see the invite link.**
