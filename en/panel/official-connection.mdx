## Description

The official connection uses the Meta **WhatsApp Cloud API**. It is the way
marked as **Recommended** in the panel. The comparison with the
unofficial way is in [WhatsApp connection](/en/definitions/connection).

## Connection paths

The paths lead to the same result, with different requirements:

| Path | When to use | Requirement |
|---|---|---|
| **Connect with Facebook** | Default. You have access to the Facebook of the business | The Facebook account |
| **Facebook connection link** | The person with Facebook does not manage the panel | None for the recipient of the link |
| **Manual setup (Meta)** | You already have your own app and tokens at Meta | System user token and Meta IDs |
| **Manual setup (Gupshup)** | You operate the number through Gupshup. Only on **v2** instances | App name and Gupshup API key |

## Connect with Facebook

<Steps>
  <Step title="Start">
    Click **Connect with Facebook**. The panel opens the official Meta flow.
  </Step>
  <Step title="Authorize at Meta">
    Follow the Meta flow to authorize the connection of the number.
  </Step>
  <Step title="Wait">
    The panel shows *Waiting for Facebook connection* and then *Connecting instance*.
  </Step>
</Steps>

At the end, the panel shows *Instance connected* and *Connected successfully*.

<Note>
To connect a number of the WhatsApp Business app, follow the **Coexistence
mode** procedure on this page.
</Note>

| Message | Cause | Action |
|---|---|---|
| *Facebook login was not completed.* | The flow was interrupted | Repeat the procedure |
| *Facebook SDK not loaded.* | The Meta SDK did not load | Refresh the page and try again |

If the Embedded Signup does not fill in everything, the panel asks for two
identifiers:

| Field | Required | Validation |
|---|---|---|
| **Phone number ID** | Yes | Numeric identifier of the number at Meta |
| **WABA ID** | Yes | Identifier of the WhatsApp Business Account |

Both values are in the **Meta Business Suite**, in the number configuration of
the business account. After you enter them, click **Exchange token and connect**. Success: *Connected successfully*. Failure: *Error exchanging token*.

## Facebook connection link

This path is the official equivalent of FastLink. The panel generates a link for
another person to connect through Meta without signing in to the panel.

<Steps>
  <Step title="Generate the link">
    Wait for *Generating connection link...*. Click **Open connection link** or copy the link.
  </Step>
  <Step title="Send the link">
    Send the link to the person with access to the Facebook of the business.
  </Step>
</Steps>

If the generation fails, the panel shows *Could not generate the connection link* and the **Try again** button.

The recipient opens the **WhatsApp Cloud API Connection** page, at the `meta-connection/[token]` route, with the **Connect
with Facebook** button. The state appears as **Waiting**, **Connecting**, or
**Connected**. On completion: *Connected successfully!*

If the link is no longer valid, the page responds *Invalid connection link* or
*Error loading connection link*. Generate a new link in the panel.

## Manual setup (Meta)

The dialog is named *WhatsApp Cloud API - Manual setup (Meta)*.

| Field | Required | Validation |
|---|---|---|
| **System user token** | Yes | Access token generated at Meta |
| **Phone number ID** | Yes | Numeric identifier of the number |
| **Meta business account ID** | Yes | Identifier of the business account |
| **Webhook forward URL** | No | URL to forward the events to |

Click **Connect Cloud API**. Success: *Cloud API connected successfully.* Failure: *Error connecting Cloud API. Please try again.*

Then point the Meta webhook to ZapperHub. The section **Meta Webhook configuration** shows the **Callback URL** and the **Verification Token**.

<Steps>
  <Step title="Open the Facebook Developers Console" />
  <Step title="Open the configuration of your app" />
  <Step title="Open the Webhooks section" />
  <Step title="Paste the Callback URL in the corresponding field" />
  <Step title="Paste the Verify token in the verification field" />
  <Step title="Save the settings" />
  <Step title="In the event list, confirm the subscription to the message events" />
</Steps>

At the end, click **Finish**.

## Manual setup (Gupshup)

Use this path when the number already operates through Gupshup. The option
appears only on **v2** instances. The version appears in the instance list. The
connection type becomes **Gupshup**.

| Field | Required | Validation |
|---|---|---|
| **App name** | Yes | The app name at Gupshup |
| **Gupshup API Key** | Yes | The key of the Gupshup account |
| **Connected phone number** | Yes | Digits only, with the country code |
| **Webhook forward URL** | No | URL to forward the events to |

On connection, the screen shows the **Callback URL**. Gupshup does not use a
verify token. Configure the URL in the Gupshup panel:

<Steps>
  <Step title="Open your app at Gupshup" />
  <Step title="Open the Webhooks tab and click Add Webhook" />
  <Step title="Name the webhook, such as ZapperHub, and paste the Callback URL in callback URL" />
  <Step title="In Payload Format, select Gupshup format (v2)" />
  <Step title="In Message Events, check Message and Sent" />
  <Step title="Save the settings" />
</Steps>

## Coexistence mode

In **Coexistence**, the number continues to work in the
WhatsApp Business app on the phone and, at the same time, responds through the
official API. The panel marks these connections with the **Coexistence** label.

The Meta flow does not have a separate option for WhatsApp Business. Meta turns
on coexistence when it detects that the number you enter is on the app.

### Requirements

- The number is in use on the **WhatsApp Business** app, version 2.24.17 or later.
- The number is not connected to the Cloud API through a different provider.
- The phone with the app is near you, unlocked, and online.

### Procedure

<Steps>
  <Step title="Start">
    Click **Connect with Facebook**. To connect
    through a different person, send the connection link.
  </Step>
  <Step title="Select the number option">
    On the Meta phone number screen, select **Enter a new phone number**.
  </Step>
  <Step title="Enter the number">
    Type the number of the WhatsApp Business app, with the country code. Meta
    detects the app and shows the business profile of the number.
  </Step>
  <Step title="Confirm the profile">
    Confirm the profile and select the business portfolio.
  </Step>
  <Step title="Confirm on the phone">
    In the WhatsApp Business app, follow the Meta instructions to confirm the
    connection.
  </Step>
  <Step title="Complete">
    Complete the Meta flow.
  </Step>
</Steps>

### Result

The panel shows *Instance connected* and the
**Coexistence** label. The number continues to work in the WhatsApp Business
app.

<Note>
If Meta asks for a code by SMS or call, it did not detect the number as
WhatsApp Business. Cancel the flow and check the requirements.
</Note>

## After the connection

The screen shows the state of the number at Meta:

| Information | Values |
|---|---|
| **Meta status** | **Pending activation** or **Ready for use** |
| **Meta App connection** | **Connected** or **Not connected**. The **Subscribe to Meta App** button fixes the second one |
| **Verified name** | The name approved by Meta |
| **New conversations limit (24h)** | 250, 2,000, 10,000, 100,000 conversations, or **Unlimited conversations** |
| **Quality rating** | **High quality**, **Medium quality**, **Low quality**, or **Not enough data** |

### Register the number

Click **Register number**. Enter the **6-digit PIN**. The panel registers the PIN if it does not exist yet. Keep the
PIN to register changes of the profile name. The registration takes a few
seconds. Success: *Number registered successfully.*

The same operation exists in the API. See
[Register phone number](/api-reference/cloud-api/registrar-número-de-telefone).

### Business profile data

**Edit profile data** opens the profile form: **About**, **Description**, **Address**, **Email**, **Websites**, and **Category**. In **Websites**, type
the URL and press Enter or space to add.

**Edit display name** changes the business name shown
to users.

<Note>
The display name change is subject to Meta approval. The name does not change
immediately.
</Note>
