## Description

The instance list is the entry point of the panel. You reach it when you sign
in. Each instance corresponds to one number. The concept is in
[WhatsApp connection](/en/definitions/connection).

With no instance, the screen shows *No instances found* and the shortcut **Create an instance now**.

## List columns

| Column | Content |
|---|---|
| **Name** | The label of the instance |
| **ID** | The identifier used in API calls |
| **X-Api-Key** | The key of the instance, hidden by default |
| **URL** | The address of the instance |
| **Version** | The running version |
| **Type** | The connection type |
| **Phone** | The connected number |
| **Status** | **Connected**, **Disconnected**, or **Not connected** |
| **Actions** | The action menu of the row |

The key is masked. Use **Show key** and **Hide key** to toggle. This is the instance key, sent in the `x-api-key` header. The
account key is in [Global API key](/en/panel/global-api-key).

## Search and filter

- **Search by name...** filters the list by label.
- **Connection status** filters by state. **All statuses** turns the filter off.
- **Tags** filters by one or more tags. **No tag** shows the instances without tags.
- The filters combine.
- The list is paginated, with the indicator *Page X of Y*.

The tag filter is kept in the page address. A reload keeps the view, and the link
can be shared.

## Tags

Each row shows the tags of the instance. When not all fit, the **+N** indicator
shows the rest.

The tag button next to the name opens the selector. Click a tag to apply it.
Click again to remove it. To create a tag, type the name and choose the color.

Limits and deletion are in [Tags](/en/panel/tags).

## Create an instance

<Steps>
  <Step title="Start">
    Click **New instance**. The panel opens *Create new instance*, with the monthly cost notice.
  </Step>
  <Step title="Confirm">
    Click **Yes, create new instance**.
  </Step>
</Steps>

The panel confirms with *Instance created successfully*.

With an overdue subscription, the button is disabled, with the message *You need to renew your subscription to create an instance*. See
[Account and subscription](/en/panel/account-and-subscription).

## Actions of each instance

| Action | Function | Effect on the active connection |
|---|---|---|
| **Copy ID** | Copies the identifier | None |
| **Copy URL** | Copies the address | None |
| **Copy X-Api-Key** | Copies the instance key | None |
| **Edit instance name** | Opens a dialog to change the label | None |
| **Connect instance** | Opens the connection flow | Starts a new connection |
| **Disconnect instance** | Ends the session of the number | Ends the connection. The status goes to **Disconnected**. The instance stops sending and receiving until it reconnects |
| **Restart instance** | Restarts the instance service | Interrupts the service during the restart. The connection returns at the end |
| **Delete instance** | Removes the instance from the account | Irreversible. See below |

During execution, the screen shows a progress message. At the end, it confirms
with *Instance disconnected*, *Instance restarted*, or *Instance deleted*. If
the restart fails: *An error occurred while restarting the instance. Please try again later.*.

### Rename

The dialog *Edit instance name* has the field **Instance name**, free text and required.

Success: *Instance name updated successfully*. Failure: *Error updating name. Please try again
later.*. A rename does not affect the ID, the key, or the connection.

### Delete

<Warning>
**The deletion cannot be undone.** When you delete an instance:

- The instance leaves the list. The ID and the API key stop working. Every integration that uses them fails.
- The connection with the number is ended.
- The message log of the instance is no longer accessible through the panel. Export or query the history before you delete.
- To use the same number again, create a new instance and connect it. It will have another ID and another key.

To stop temporarily, use **Disconnect instance**, which is reversible.
</Warning>

The dialog *Confirm deletion* asks for confirmation. Click **Yes, delete**.

Instances created by a partner are not deleted through the panel. The message
*Instance created by partner [name]. Delete it in the partner application* says
that the deletion must be done in the system that created it.

## Instance panel

When you open an instance, you reach its panel, at the `dash/instances/[id]`
route.

### Indicators

Four cards at the top. Each one has the shortcut **View messages**, which opens the log already filtered:

| Indicator | Count |
|---|---|
| **In Progress** | Messages in processing at this moment |
| **In Queue** | Messages waiting for processing |
| **Failed** | Messages that ended in error |
| **Processed messages** | Total processed |

The queue concept is in [Message queue](/en/definitions/queue).

### Summary

The **Summary** card shows the volume of the instance:

- Messages processed today.
- Messages processed this month.
- Messages processed last month.
- Messages processed in the last 90 days.
- Average messages processed per day.

To investigate a message, use the [Message log](/en/panel/message-log).
