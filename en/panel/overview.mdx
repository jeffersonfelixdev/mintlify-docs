## Description

The panel is where you create instances, connect numbers, follow messages, and
adjust the behavior of each instance. This page describes the organization of the
panel and points to the page of each area.

## Entry to the panel

When you open the panel address, the panel redirects you. There is no home screen.

- Without an active session: you go to the sign-in screen. See [Account and subscription](/en/panel/account-and-subscription).
- With an active session: you go to the instance list.

The `dash` address also redirects to the instance list. The instance list is the
entry point of the panel.

## Side menu

The side menu is fixed on all screens. It has two groups.

### Navigation

| Area | Function | Page |
|---|---|---|
| **Instances** | Lists the instances of the account and gives access to each one | [Instances](/en/panel/instances) |
| **Settings** | Account and registration data | [Account and subscription](/en/panel/account-and-subscription) |
| **Global API Key** | Key of the Instance API, to create and manage instances | [Global API key](/en/panel/global-api-key) |
| **My subscription** | Opens the customer portal in a new tab | [Account and subscription](/en/panel/account-and-subscription) |

**My subscription** is not a panel screen. The item opens the customer portal in
a new tab. In the portal, you see invoices, change the payment method, and cancel
the subscription.

### Support

Three shortcuts open in a new tab: **Documentation** (this site),
**Talk to Zack** (support through WhatsApp), and **Community**. Below them, **Sign out** ends the session.

## Language of the panel

The panel is available in Portuguese, English, Spanish, German, Italian, and
Turkish. The language menu shows the flag of the current language. It is at the
bottom of the side menu, at the top of each screen, and on the sign-in screen.

On the first access, the panel uses the language of the browser if it is
Portuguese, English, or Spanish. For other languages, the panel uses Portuguese.
To change the language, select it in the language menu. The panel keeps the
selection for one year in this browser.

<Note>
The public screens are only in Portuguese, except the sign-in screen. See
[Account and subscription](/en/panel/account-and-subscription).
</Note>

## Two different keys

The panel exposes two keys. They are not interchangeable:

| Key | Location | Function |
|---|---|---|
| **Global API Key** | Side menu > Global API Key | Create and manage instances through the Instance API |
| **Instance API key** | In the instance row, in the list | Send messages and operate the instance through the API |

The difference between the two, with the HTTP header of each one, is in
[Global API key](/en/panel/global-api-key).
