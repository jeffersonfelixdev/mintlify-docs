## Description

The Instagram connection links a professional account to the instance, to handle
direct messages and interactions.

## Preliminary requirements

- A professional Instagram account (business or creator). Personal accounts
  cannot be connected. Convert the account in Instagram before you start.
- Sign-in access to that account.

## Procedure

<Steps>
  <Step title="Open the connection page">
    Click **Connect with Instagram**. The panel opens the connection page in a new tab.
  </Step>
  <Step title="Sign in and authorize">
    Sign in to the professional account and authorize the access. This step happens in Instagram.
  </Step>
  <Step title="Return to the panel">
    Return to the connection page to see the status.
  </Step>
</Steps>

The flow goes through three screens:

1. **Instagram Connection**, at the
   `instagram-connection/[token]` route. The screen shows *Loading connection data...* and then *Redirecting to Instagram...*. If the link is no longer valid, it responds *Invalid connection link* or *Error loading connection link*. Generate a new link in the
   panel.
2. **Authorization in Instagram.** You sign in to the account and authorize the access.
3. **Instagram Authorization**, at the
   `instagram/authorize` route. The screen shows *Authorizing connection...* and, on completion, *Connection completed successfully!*. You can close the window.

## Result

In the panel, the connection page shows *Instance connected successfully!* The
connection type of the instance appears as **Instagram**.

## Errors

| Message | Cause | Action |
|---|---|---|
| *Authorization code not found.* | The Instagram return came without the code | Redo the authorization |
| *Connection session not found.* | The session expired | Restart from the connection link |
| *Could not determine the authorization redirect URL.* | The return address could not be resolved | Generate a new link |
| *Error authorizing Instagram connection.* | The authorization failed in Instagram | Try again |
| *Error checking connection status.* | The panel could not query the state | Try again |

All error screens have the **Try again** button. If the
error persists, generate a new connection link in the panel.
