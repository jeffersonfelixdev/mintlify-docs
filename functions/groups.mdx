## Operações

A API permite estas operações em grupos:

- Criar um grupo ou uma comunidade.
- Consultar os detalhes de um grupo.
- Atualizar o nome e a foto de um grupo.
- Adicionar e remover participantes.
- Promover um participante a administrador e remover essa permissão.
- Gerar o link de convite.
- Listar os grupos de que o número participa.
- Listar os participantes de um grupo.

Para enviar texto e mídia a um grupo, use as rotas de
[Envio de mensagens](/functions/sending-messages) com o JID do grupo em `jid`.

<Note>
Se o número conectado não é administrador do grupo, a Meta pode ocultar o
telefone dos participantes. Nesse caso, a API mostra o LID do contato no lugar
do número.
</Note>
