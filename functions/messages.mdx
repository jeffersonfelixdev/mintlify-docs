## Descrição

A ZapperHub envia mensagens para contatos, grupos, comunidades e canais.

## Tipos de mensagem

- Texto
- Imagem, com ou sem legenda
- Áudio
- Nota de voz (como gravada no aparelho)
- Nota de voz gerada a partir de um texto
- Vídeo
- Documento
- Contato (vCard)
- Sticker
- Localização
- Botões de ação ou de resposta rápida
- Lista de opções (menu interativo)
- Carrossel (apenas em conexão oficial)
- Template aprovado pela Meta (apenas em conexão oficial)

## Destinos

| Destino | Sufixo |
|---|---|
| Número de telefone | `@s.whatsapp.net` |
| Identificador único do usuário | `@lid` |
| Grupo | `@g.us` |
| Status | `status@broadcast` |
| Canal | `@newsletter` |

## Outras operações

Além de enviar, a API permite reagir a uma mensagem, marcar mensagens como lidas
e excluir uma mensagem enviada.

A rota, os campos, os limites e as diferenças entre conexão oficial e não oficial
de cada tipo estão em [Envio de mensagens](/functions/sending-messages).
