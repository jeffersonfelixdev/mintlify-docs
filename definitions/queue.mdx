## Descrição

Cada instância tem uma fila única de envio. Toda mensagem passa pela fila:
texto, imagem, vídeo, documento e áudio, para pessoas ou grupos.

A fila protege o número contra bloqueios. Ela aplica um intervalo entre as
mensagens, em quatro níveis:

| Nível | Intervalo |
|---|---|
| `shortest` | de 1 a 3 segundos |
| `short` | de 5 a 10 segundos |
| `medium` | de 15 a 45 segundos |
| `long` | de 60 a 90 segundos |

Você também pode adicionar um atraso antes de cada envio, com o status
*Digitando* ou *Gravando áudio*. Esse recurso dá um ritmo mais humano ao chatbot.
Para alterar essas opções, veja
[Atualizar configurações](/api-reference/configurações/atualizar-configurações).

## Resposta da API

Como o envio passa pela fila, a resposta da API confirma o enfileiramento, não a
entrega. A ZapperHub tenta cada mensagem até 5 vezes. Quando as tentativas se
esgotam, a ZapperHub publica o webhook
[`messages.error`](/integrations/webhooks#falha-no-envio-de-mensagens).

<Warning>
**A fila não pode ser desligada.** Não é possível enviar mensagens simultâneas
para pessoas ou grupos diferentes, nem fazer transmissões (broadcast). O uso
indevido é penalizado conforme os
[Termos de Uso](https://zapperhub.com/terms-of-use).
</Warning>

<Note>
O status *Digitando* ou *Gravando áudio* não está disponível em grupos.
</Note>
