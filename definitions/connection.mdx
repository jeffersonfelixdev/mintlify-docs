## Instância

Uma instância é um serviço da ZapperHub que faz a comunicação com um número de
WhatsApp. Cada instância conecta um único número.

Cada instância roda em um ambiente isolado. O uso de recursos de uma instância
não afeta outra instância, mesmo na mesma conta. Esse isolamento garante
ambientes separados para cada cliente seu.

## Formas de conexão

| Forma | Tipo | Descrição |
|---|---|---|
| **Conectar com Facebook** | API oficial | Recomendada. A Meta guia a autorização do número no próprio site dela. |
| **Configuração manual (Meta)** | API oficial | Você cria um app na Meta, gera os tokens e cadastra o webhook. |
| **Gupshup** | API oficial | Para quem já opera o número pela Gupshup. O webhook é configurado na Gupshup, não na ZapperHub. |
| **QR Code** | API não oficial | O celular lê um QR Code em **Dispositivos conectados** > **Conectar dispositivo**. |
| **Código de pareamento** | API não oficial | Você digita no celular um código de 8 letras e números. |
| **FastLink** | API oficial e não oficial | Um link temporário para outra pessoa conectar o número, sem acesso ao painel. Indicado para agências. |
| **ZapperHub Connect** | API não oficial | Extensão do Chrome para aparelhos que exigem chave de acesso no WhatsApp Web. Veja [ZapperHub Connect](/definitions/zapperhub-connect). |
| **Instagram** | Instagram | Conecta uma conta profissional do Instagram à instância, para mensagens diretas e interações. |

Na conexão por QR Code ou por código de pareamento, a instância funciona como o
WhatsApp Web. O celular registra a instância como um dispositivo conectado.

<Warning>
**Risco de bloqueio.** A conexão não oficial está sujeita a restrições e
bloqueios da Meta. Use a API oficial da Meta sempre que possível. A ZapperHub é
Meta Business Provider: você não precisa criar apps nem fazer configurações
manuais, e a ZapperHub cuida do suporte junto à Meta.
</Warning>
