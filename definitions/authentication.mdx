## Descrição

Todas as rotas da API da instância exigem autenticação por token. A única exceção
é a rota de status da API.

O token é a chave **X-Api-Key** da instância. Ela aparece na linha da instância,
na lista de instâncias do [painel](https://app.zapperhub.com/dash). Se você não
tem acesso ao painel, peça a chave ao administrador da conta.

A conta tem também uma chave global, usada só na Instance API. Veja
[Chave de API global](/painel/chave-de-api-global).

## Como enviar o token

Envie o token no cabeçalho `X-Api-Key` de cada requisição:

```http
X-Api-Key: sk_token_de_exemplo_123
```

<Warning>
**Proteja a chave.** Não envie a chave de API a terceiros. A equipe da ZapperHub
nunca pede a chave para dar suporte. Guarde a chave em um armazenamento seguro.
</Warning>
