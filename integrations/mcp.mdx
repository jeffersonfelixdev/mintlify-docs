## Descrição

O servidor MCP da ZapperHub deixa um agente de IA operar o WhatsApp das suas
instâncias. O agente lista as instâncias, lê conversas, espera uma resposta e
envia mensagens. Ele usa as ferramentas do MCP e não precisa de código de
integração.

O servidor atende instâncias dos tipos `device` (conexão não oficial) e
`cloud_api` (conexão oficial). Cada conexão acessa só as instâncias da própria
conta.

| Item | Valor |
|---|---|
| URL | `https://mcp.zapperhub.com/mcp` |
| Transporte | Streamable HTTP |
| Autenticação | Login da conta (OAuth) ou cabeçalho `Authorization: Bearer zsk_...` |

<Note>
O agente nunca recebe a chave de uma instância. O servidor usa as credenciais
das instâncias por conta própria, e nenhuma ferramenta as devolve.
</Note>

## Escolher como conectar

Há duas formas de conectar. Escolha pelo cliente.

| Cliente | Forma de conectar |
|---|---|
| Claude.ai, Claude Desktop e ChatGPT | [Login da conta](#conectar-com-o-login-da-conta). Você não cola nenhuma chave |
| Claude Code, Cursor, Hermes e OpenClaw | [Chave da conta](#conectar-com-a-chave-da-conta), em um cabeçalho do cliente |

Um cliente MCP remoto que aceita login (OAuth) descobre a tela de login sozinho.
Outro cliente sem essa função usa a chave da conta.

## Conectar com o login da conta

Com o login da conta, você entra na ZapperHub e escolhe o que o agente acessa.
Você não copia nenhuma chave. A conexão fica na lista
[Aplicativos conectados](/painel/aplicativos-conectados), onde você edita ou
revoga o acesso.

### Pré-requisitos

- Uma instância conectada. Veja [Início rápido](/quickstart).
- Um cliente que aceita servidor MCP remoto com login (OAuth).

### Tela de autorização

Depois do login, a ZapperHub mostra a tela de autorização. Ela traz o nome do
aplicativo e o endereço dele. Escolha o que o aplicativo acessa e clique em **Autorizar**. Para
desistir, clique em **Cancelar**. Em ambos os casos, você volta ao aplicativo.

<Warning>
Confira o endereço que a tela mostra ao lado do nome. Ele deve ser o do
aplicativo que você conecta, por exemplo `claude.ai`. Se o endereço for outro,
clique em **Cancelar**.
</Warning>

A tela tem duas escolhas.

| Escolha | Opção | O que libera |
|---|---|---|
| **Instâncias** | **Todas as instâncias** | Todas as instâncias da conta, também as que você criar depois |
| | **Somente as selecionadas** | Só as instâncias que você marcar. Marque ao menos uma |
| **Acesso** | **Somente leitura** (padrão) | Ver mensagens e conversas. O agente usa 7 ferramentas |
| | **Leitura e escrita** | Ver e enviar mensagens. O agente usa as 12 ferramentas |

As 7 ferramentas do acesso **Somente leitura** são `list_instances`,
`list_chats`, `read_messages`, `wait_for_reply`, `check_numbers`,
`get_service_window` e `list_templates`. O acesso **Leitura e escrita** soma
`send_text`, `send_media`, `send_template`, `react` e `mark_as_read`. Com
**Somente leitura**, o agente não vê as ferramentas de escrita.

Nas duas opções, o agente também vê a lista das instâncias autorizadas, com
nome, número, status e tags.

Depois de autorizar, o cliente guarda a conexão e renova o acesso sozinho. Você
não cola chave e não entra de novo a cada uso.

### Editar ou revogar a conexão

Cada aplicativo conectado aparece em [Aplicativos conectados](/painel/aplicativos-conectados),
no menu lateral do painel. Nessa tela, você muda as instâncias e o acesso com
**Editar** e retira o acesso com **Revogar**. A mudança vale na próxima chamada
do agente.

Revogar uma conexão não afeta a chave da conta nem as outras integrações.
Rotacionar ou excluir a chave da conta também não afeta uma conexão por login.

## Conectar com a chave da conta

A chave da conta é a alternativa para os clientes que aceitam cabeçalhos
próprios: Claude Code, Cursor, Hermes e OpenClaw. O agente tem o acesso da chave:
escrita em todas as instâncias da conta.

### Pré-requisitos

- Uma instância conectada. Veja [Início rápido](/quickstart).
- A chave global da conta, que começa com `zsk_`.
- Um cliente MCP que aceita Streamable HTTP e cabeçalhos próprios.

### Gerar a chave da conta

<Steps>
  <Step title="Abra a tela da chave">
    Acesse [app.zapperhub.com/dash](https://app.zapperhub.com/dash) e clique em **Global API Key** no menu lateral.
  </Step>
  <Step title="Crie a chave">
    Clique em **Criar chave global**.
  </Step>
  <Step title="Copie a chave">
    Copie a chave e guarde-a no cliente MCP. O painel mostra a chave uma única vez.
  </Step>
</Steps>

A chave da conta é a mesma chave global da Instance API. A tela, a rotação e a
exclusão estão em [Chave de API global](/painel/chave-de-api-global).

<Warning>
A chave da conta dá ao agente escrita em todas as instâncias da conta. Guarde-a
como um segredo. Não a coloque em código versionado. Se você rotacionar ou
excluir a chave, o cliente MCP perde o acesso até você atualizar o cabeçalho.
</Warning>

### Configurar o cliente

Em todos os clientes, o endereço é `https://mcp.zapperhub.com/mcp` e o cabeçalho
é `Authorization: Bearer zsk_...`. Troque `zsk_...` pela sua chave.

<Tabs>
  <Tab title="Claude Code">
    Execute o comando no terminal:

    ```bash
    claude mcp add --transport http zapperhub https://mcp.zapperhub.com/mcp --header "Authorization: Bearer zsk_..."
    ```
  </Tab>
  <Tab title="Cursor">
    Adicione o servidor ao arquivo `mcp.json`:

    ```json mcp.json
    {
      "mcpServers": {
        "zapperhub": {
          "url": "https://mcp.zapperhub.com/mcp",
          "headers": {
            "Authorization": "Bearer zsk_..."
          }
        }
      }
    }
    ```
  </Tab>
  <Tab title="Hermes">
    Adicione o servidor à chave `mcp_servers` do arquivo `~/.hermes/config.yaml`:

    ```yaml config.yaml
    mcp_servers:
      zapperhub:
        url: "https://mcp.zapperhub.com/mcp"
        headers:
          Authorization: "Bearer zsk_..."
    ```
  </Tab>
  <Tab title="OpenClaw">
    Execute o comando no terminal:

    ```bash
    openclaw mcp set zapperhub '{"url":"https://mcp.zapperhub.com/mcp","transport":"streamable-http","headers":{"Authorization":"Bearer zsk_..."}}'
    ```
  </Tab>
  <Tab title="Outro cliente">
    Use qualquer cliente MCP que aceite Streamable HTTP e cabeçalhos próprios.
    Informe a URL `https://mcp.zapperhub.com/mcp` e o cabeçalho
    `Authorization: Bearer zsk_...`.
  </Tab>
</Tabs>

## Testar a conexão

Depois de conectar, por login ou por chave, peça ao agente para listar as
instâncias. A resposta confirma que a conexão funciona.

## Ferramentas

O servidor expõe 12 ferramentas. Elas têm nomes e descrições em inglês, para o
agente. Em toda ferramenta, `instance` é o id ou o nome de uma instância de
`list_instances`. `chat` é um número com código do país, um id de grupo que
termina em `@g.us` ou um LID que termina em `@lid`.

### Ler e consultar

| Ferramenta | O que faz |
|---|---|
| `list_instances` | Lista as instâncias da conta, com id, nome, número, tipo, status e tags. Chame primeiro: as outras ferramentas usam um id ou um nome desta lista |
| `list_chats` | Lista as conversas mais recentes de uma instância, da mais nova para a mais antiga, com a última mensagem. `limit` de 1 a 50 |
| `read_messages` | Lê as mensagens de uma conversa, da mais antiga para a mais nova. `after` e `before` aceitam um cursor para paginar. `limit` de 1 a 100. As mensagens enviadas pela conta mostram o status do envio |
| `wait_for_reply` | Espera uma mensagem nova do contato ou do grupo e devolve as mensagens recebidas e um `cursor` novo. `after` é obrigatório: use o `cursor` de um envio ou de `read_messages`. `timeout_seconds` de 1 a 60, padrão 50. Sem mensagem no prazo, devolve `timedOut: true`. As mensagens devolvidas podem incluir reações e avisos do sistema |
| `check_numbers` | Confere se até 50 números têm WhatsApp e devolve o JID de cada um |
| `get_service_window` | Diz se a janela de 24 horas está aberta para um contato. Só faz diferença em `cloud_api` |
| `list_templates` | Lista os templates de uma instância `cloud_api`, com nome, idioma, status, categoria e componentes |

### Enviar

| Ferramenta | O que faz |
|---|---|
| `send_text` | Envia uma mensagem de texto a um contato ou grupo. Até 4096 caracteres |
| `send_media` | Envia uma imagem, vídeo, áudio ou documento a partir de uma URL pública, com legenda e nome de arquivo opcionais. Um documento precisa de nome: sem `filename`, o servidor usa o nome de arquivo do fim da URL. Uma URL de endereço privado ou interno é recusada com `INVALID_MEDIA_URL` |
| `send_template` | Envia um template aprovado em uma instância `cloud_api`. Serve para iniciar uma conversa ou quando a janela de 24 horas está fechada |
| `react` | Reage a uma mensagem com um emoji. Um texto vazio remove a reação |
| `mark_as_read` | Marca mensagens recebidas como lidas. Em grupo, informe também `sender` |

Os envios entram na fila. A resposta traz `status`, `jobIds` e `cursor`. O
`cursor` vem em todo envio, também na primeira mensagem a um contato novo. Passe
esse `cursor` a `wait_for_reply` para esperar a resposta do contato.

### Status das mensagens enviadas

Em `read_messages`, cada mensagem enviada pela conta (`fromMe: true`) traz
`status`, `jobId` e, na falha, `error`. O `jobId` é um dos `jobIds` do envio.
Se a resposta do contato não chegar, leia a conversa e confira o status da
mensagem.

| `status` | Significado |
|---|---|
| `pending` | A mensagem está na conversa, sem confirmação de envio |
| `sent` | A plataforma confirmou o envio |
| `delivered` | A mensagem chegou ao aparelho do contato |
| `read` | O contato leu a mensagem |
| `failed` | O envio falhou. `error` traz `code` e `title` |

Uma mensagem apagada para todos vem com `deleted: true`, sem texto e sem mídia.

### Instâncias da API oficial

Em uma instância `cloud_api`, `send_text` e `send_media` só funcionam até 24
horas depois da última mensagem do contato. Com a janela fechada, a ferramenta
responde `SERVICE_WINDOW_CLOSED`. Nesse caso, use `list_templates` e
`send_template`. Veja [Templates](/painel/templates).

### Limites

- Cada usuário pode fazer até 120 chamadas por minuto.
- `wait_for_reply` espera no máximo 60 segundos por chamada. Para esperar mais,
  chame a ferramenta de novo com o `cursor` devolvido.
- Cada conta pode ter até 10 chamadas de `wait_for_reply` ao mesmo tempo. A
  chamada seguinte responde `TOO_MANY_WAITS`.
- As ferramentas só enxergam as instâncias da conta da conexão. Em uma conexão por login, só as instâncias autorizadas.

## Agentes que rodam o tempo todo

Um agente interativo, como o Claude Code, usa `wait_for_reply` para esperar uma
resposta. Um agente que atende conversas o tempo todo recebe as mensagens por
webhook. A instância avisa o agente, e o agente responde pelas ferramentas do MCP.

<Steps>
  <Step title="Exponha uma URL no agente">
    O agente precisa de uma URL HTTPS que receba requisições `POST`.
  </Step>
  <Step title="Cadastre o webhook na instância">
    Aponte o webhook da instância para essa URL e assine o evento `messages.upsert`. O procedimento está em [Webhooks](/integrations/webhooks).
  </Step>
  <Step title="Valide a assinatura">
    Confira o cabeçalho `x-webhook-signature` de cada entrega, como descreve [Webhooks](/integrations/webhooks). A assinatura usa a chave de API da instância. Copie essa chave no painel, com **Copiar X-Api-Key** em [Instâncias](/painel/instancias), e configure-a só no código que recebe o webhook. Não coloque essa chave no cliente MCP.
  </Step>
  <Step title="Responda pelo MCP">
    A cada evento, o agente chama as ferramentas. Use `instanceId` como `instance` e `key.remoteJid` como `chat`. Por exemplo, chame `read_messages` para ler o contexto e `send_text` para responder.
  </Step>
</Steps>

O webhook também entrega as mensagens que a própria conta envia. Ignore os
eventos com `key.fromMe` igual a `true`. Sem esse filtro, o agente responde às
próprias mensagens.

Para um agente de atendimento pronto, sem servidor próprio, veja
[Agentes de IA](/integrations/ai-agents).

## MCP da documentação

A documentação da ZapperHub também tem um servidor MCP, em
`https://docs.zapperhub.com/mcp`. Ele permite que o agente pesquise nesta
documentação. Ele não exige chave e não acessa as suas instâncias. Adicione-o ao
cliente da mesma forma, sem o cabeçalho `Authorization`. No Claude Code:

```bash
claude mcp add --transport http zapperhub-docs https://docs.zapperhub.com/mcp
```
