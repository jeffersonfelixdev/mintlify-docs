<Warning>
**Mudança no campo `type` a partir de 10/09/2026.** A rota
`POST /{instanceId}/integrations` aceita só `CHATVOLT` em `type`. Requisições com
`GPTMAKER` ou `ZAIA` respondem `400`. Antes, respondiam `204`.

- Se a sua integração já usa `CHATVOLT`, nada muda.
- Se você envia `GPTMAKER` ou `ZAIA`, a chamada falha.

Integrações desses dois provedores já cadastradas continuam a funcionar enquanto
a API legada estiver no ar. Elas não podem mais ser criadas nem atualizadas por
esta rota. Para seguir com um agente de IA, migre para a Chatvolt. Veja
[Chatvolt AI](/integrations/chatvolt).

A API recusa esses provedores para evitar uma falha silenciosa: uma integração
com um provedor não processado nunca responderia.
</Warning>

## Descrição

Um agente de IA responde automaticamente as conversas de uma instância. A
ZapperHub encaminha as mensagens recebidas à **Chatvolt** e devolve ao WhatsApp a
resposta do agente.

<Note>
GPT Maker e Zaia seguem atendidos enquanto a API legada estiver no ar, mas não
aceitam novos cadastros. Integrações criadas hoje usam a Chatvolt.
</Note>

A integração é por instância. Cada número conectado pode ter o seu próprio
agente, ou nenhum. O agente atende todas as conversas da instância. Você pode
desligar o agente em uma conversa sem afetar as outras, com os comandos `#on` e
`#off`.

## Pré-requisitos

Na plataforma do agente, tenha em mãos:

- O **ID do Agente**, que identifica qual agente responde.
- A **Chave de API** da plataforma, que autoriza a ZapperHub a usá-la.

Esta página explica o que a integração faz e como controlá-la. O procedimento no
painel está em [Integrações](/painel/integracoes).

## Integrar um agente

### Pela API

Use a rota
[Criar/atualizar integração](/api-reference/integrações/criaratualizar-integração).
Informe no corpo:

- `type`: sempre `CHATVOLT`.
- `agentId`: o id do agente.
- `apiKey`: o token de API da sua conta na Chatvolt.

### Pelo painel

<Steps>
  <Step title="Abra a instância">
    Acesse [app.zapperhub.com/dash](https://app.zapperhub.com/dash) e clique na instância.
  </Step>
  <Step title="Abra a aba de agentes">
    Clique em **Integrações** e depois em **Agentes de IA**.
  </Step>
  <Step title="Preencha e salve">
    Preencha **Tipo de Integração**, **ID do Agente** e **Chave de API**. Clique em **Atualizar**.
  </Step>
</Steps>

Cada campo, com a obrigatoriedade e a validação, está em
[Integrações](/painel/integracoes).

## Controlar o agente pelo WhatsApp

Os comandos valem por conversa. Desligar a IA para um contato não afeta os outros.

| Objetivo | Origem | Comando |
|---|---|---|
| Desativar o agente | API | Envie ao contato uma mensagem de texto `#off` |
| Desativar o agente | Celular, WhatsApp Web ou Desktop | Envie `#off`. Ou configure a instância para desativar com qualquer mensagem de texto |
| Reativar o agente | API, celular, WhatsApp Web ou Desktop | Envie `#on` |

### Desativar a IA com qualquer mensagem do dispositivo

<Steps>
  <Step title="Abra as configurações da instância">
    Na instância, clique em **Configurações**.
  </Step>
  <Step title="Ative a opção">
    Na aba **Integração**, ative **Desativar IA em mensagens a partir do dispositivo**.
  </Step>
</Steps>

Com a opção ativa, o agente para de responder naquela conversa quando o dono da
linha responde pelo celular, pelo WhatsApp Web ou pelo Desktop. Mensagens
enviadas pelas rotas da API não acionam essa pausa. Para elas, use `#off`.

As outras opções de comportamento, inclusive o **Debounce**, que agrupa as
mensagens antes de enviá-las ao agente, estão em
[Configurações da instância](/painel/configuracoes-da-instancia).
